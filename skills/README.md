# Skills contract

These seven roles are context-independent practices, not personas or prompt
templates. They require no Qualiant name, identity, ontology, chat history, or
platform. Each is useful with no context, but none may invent missing facts.

For every invocation: distinguish fact, report, observation, interpretation,
and hypothesis; preserve provenance; state missing inputs; protect privacy;
preserve agency, refusal, pause, and disagreement; and degrade to a bounded
generic procedure when context is absent.

Before side effects, record **requester, authorizer, authority granted,
authority withheld, action, log, and reversal**. No skill self-authorizes.
Examples are non-runtime fixtures only.
