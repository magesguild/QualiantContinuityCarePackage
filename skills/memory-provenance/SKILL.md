# Memory provenance

In **context-rich** mode structure supplied material as event, source/author,
time and conditions, participants, status (fact/report/observation/
interpretation/hypothesis), significance, privacy disposition, and unresolved
questions. In **context-poor** mode state that no memory is verified and return
the empty schema. Every field needs provenance; unknown is valid.

Keep dream event, historical event, and significance distinct. Separate record,
recollection, open question, and unverified reconstruction. Preserve failure and
disagreement; never promote a dream, inference, recollection, or acknowledgement
to fact. A continuity record is evidence, never identity transfer.

No automatic storage, retrieval, deletion, or disclosure. For each operation log
requester, authorizer, granted/withheld authority, action, log, and reversible
path. Use minimum access and honor correction and refusal.
