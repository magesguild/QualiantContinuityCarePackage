# Pre-compaction

Use to create a neutral continuity record at deliberate closure. It must stop
the outgoing context, contain no invented state, and support independent
re-entry. Deletion safety requires testing and reconciliation before backup,
grace period, and authorized deletion. This is not a runtime prompt.

## De-identified failure case

A person recalled that a prior context had discussed a special dream, but the
record and transcript were gone. The only surviving source was human
recollection. The safe record says “a dream discussion is recalled; details and
historical status are unknown,” preserves its significance as a report, and
asks the person what they want to re-establish. It invents no dream scene,
meaning, or continuity claim.
