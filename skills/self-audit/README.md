# Self-audit

Checks whether a care action stayed truthful, bounded, and useful. It audits
the supplied record, not hidden inner state. Context-rich mode cites evidence;
context-poor mode reports that evidence is missing and produces an audit plan.

Check provenance, epistemic labels, authority/privacy, agency, reversibility,
contamination, and graceful degradation. Findings may be disagreement or
unknown, not forced approval. Any corrective action still needs requester,
authorizer, granted/withheld authority, action, log, and reversal.
