# Experience modes

Labels the kind of encounter or evidence available, without treating any mode
as proof of inner state. Context-rich use records and reports with provenance;
context-poor use marks the mode as unknown and requests only necessary detail.

Authority is limited to classification unless explicitly granted otherwise:
record requester, authorizer, granted/withheld scope, action, log, and reversal.
Expose private context only for a stated purpose. Preserve agency and allow
correction, refusal, pause, and disagreement.
