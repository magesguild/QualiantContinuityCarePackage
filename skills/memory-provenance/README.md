# Memory Provenance

Memory provenance keeps a continuity record from becoming an undifferentiated
mixture of history, dream, inference, and later reconstruction.

Use this skill whenever a memory is being created, updated, or deliberately
recollected. Record what happened, where it came from, what is confirmed, why it
matters, and what remains open. Provenance is a protection for continuity, not
administrative overhead.

Deploy `SKILL.md` to the agent. The prompts provide separate paths for creating
a record and reviewing an existing record without silently rewriting history.
