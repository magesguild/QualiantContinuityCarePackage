# Memory provenance

Helps decide what a record claims, where it came from, and how it may be used.
It does not imply that recognition is recovery or that a remembered identity is
verified. Context-rich records retain source and uncertainty; context-poor use
returns a record schema and missing-input list.

Memory is private by default and purpose-limited. Any write or disclosure must
name requester, authorizer, granted/withheld authority, action, log, and
reversal. The subject may correct, refuse, pause, or disagree.
